NN_in_NLP_Final_Project_1_InstructionTuningAndPerformance: contains the instruction tuning itself, inspection of generated examples and performance evaluation with IFEval

NN_in_NLP_Final_Project_2_RepresentationSpaceAnalysis: contains extraction of representations, CKA, Probing, silhouette score, PCA

The results folder contains the training log including losses, and csv files with CKA and Probing results for each layer and model, each with the versions with last token and mean pool representations.

The trained models (around 500MB each) and extracted representations (around 190MB) are not in the repo due to their size.
